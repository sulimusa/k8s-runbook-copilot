# Stytch historical Kubernetes incident pattern

Original project-authored synopsis. Status: historical analogy, not current service guidance.
Pattern ID: P05

Cloud API access stopped and replacement nodes failed after a quiet interval. Historical context: Stytch reports a deleted shared instance profile, failed replacement provisioning and delayed failures on existing nodes. Exact credential expiry and role-removal API calls are fixture details, not verified historical observations. Useful checks: Inspect instance-profile references and audit history, credential expiry and trusted clock offset without exposing credentials.
