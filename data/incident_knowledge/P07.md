# Shopify historical Kubernetes incident pattern

Original project-authored synopsis. Status: historical analogy, not current service guidance.
Pattern ID: P07

Newly deployed pods fail TLS calls while old pods continue serving. Historical context: Shopify reports an expired root and stale client trust bundle; existing TLS connections concealed the problem until pod replacement forced new handshakes. Useful checks: Compare fresh versus reused connections, certificate SAN/validity, request hostname and the actual client trust store.
