# Cloudflare historical Kubernetes incident pattern

Original project-authored synopsis. Status: historical analogy, not current service guidance.
Pattern ID: P08

A stateful tool takes a long time to start after replacement. Historical context: Cloudflare reports long pod startup delays while kubelet recursively changed volume group ownership across many files. Useful checks: Establish whether delay occurs during attach, mount, ownership processing or application initialization.
