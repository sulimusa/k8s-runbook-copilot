# FREE NOW historical Kubernetes incident pattern

Original project-authored synopsis. Status: historical analogy, not current service guidance.
Pattern ID: P12

Autoscaling launched instances but application pods remain Pending. Historical context: FREE NOW reports that a moved package invalidated a hardcoded bootstrap URL, leaving launched worker instances unable to join Kubernetes. Useful checks: Compare cloud instance counts with node registration, then inspect bootstrap completion and API authentication errors.

Original synopsis and diagnostic suggestions; historical analogy is not proof of a current cause.
